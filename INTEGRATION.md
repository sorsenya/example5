# Интеграция сайта с Google Sheets

## Что важно знать сразу
1. **Из моей рабочей среды адреса Google Apps Script недоступны**, поэтому я не выполнял реальный GET к API №1 и не отправлял ничего в API №2. Код написан по контракту из документации backend (`gas-backend/docs/API.md`) и проверен в браузере на **имитации** обоих API (80 проверок). Проверьте реальные ответы: откройте `tools/check-api.html` (GET, только чтение).
2. **До заполнения таблицы разделы будут пустыми.** Backend публикует только строки со статусом **«Готово»**, а теперь вся информация (услуги, цены, курсы, города, модели, контакты) берётся только оттуда. Прежние демонстрационные карточки и прайс из кода удалены, чтобы не показывать выдуманные данные. Пока строк «Готово» нет, на сайте показываются аккуратные сообщения «скоро появится». Тексты по умолчанию остаются только у заголовков и кнопок интерфейса.
3. **Нужно переопубликовать Apps Script с обновлением:** в backend добавлен тип заявки `other` («Прочее», форма «Другой вопрос»). Без обновления эта форма вернёт ошибку `INVALID_TYPE`. Остальные формы работают и без него.

## Как загружается контент
Один запрос `GET …/exec?action=content` на страницу. Ответ сохраняется в `localStorage` (ключ `cb:content:v1`): в течение 60 секунд повторный запрос не делается; позже страница сразу показывает сохранённые данные и обновляет их в фоне. Таймаут — 12 с. Если API недоступен, показываются последние сохранённые данные; если их нет — блок с кнопкой «Повторить». Все блоки страницы берут данные из одного общего хранилища (`CB.content`). Недостающие и `null`-поля пропускаются, ничего не подставляется.

Правка в таблице видна на сайте после обновления страницы (не позже минуты).

## Как отправляются заявки
`POST` на API №2: тело — JSON, `Content-Type: text/plain;charset=utf-8` (не вызывает preflight, режим `no-cors` не используется, ответ читается). Успех показывается только после `{"success":true}`. Во время запроса кнопка заблокирована («Отправляем…»), повторная отправка не уходит; при успехе форма очищается, при ошибке (сеть, не-JSON, ответ API) введённые данные остаются. Поле `source` — адрес страницы (`/contacts/`, `/models/` …). Скрытое поле `website` — honeypot.

| Форма | Страница | `type` | Доп. поля |
|---|---|---|---|
| Запись на услугу | Контакты (вкладка «На услугу») | `service` | `desiredDate` |
| Обучение | Контакты («На обучение») | `education` | `level`, `format` |
| Наставничество | Наставничество и Контакты | `mentorship` | `currentLevel`, `goals` (`service` = «Наставничество») |
| Отклик модели | Стать моделью | `model` | `hairNow` |
| Другой вопрос | Контакты («Другой вопрос») | `other` | — |

Во всех формах: `name`, `contact`, `messenger` (`any`, `whatsapp`, `telegram`, `vk`, `instagram`, `phone`), `service`, `city`, `comment`. Кнопки «Записаться» на сайте ведут на `contacts/?type=…&service=…&city=…#form` и заполняют форму; «Откликнуться» на странице моделей подставляет процедуру и город.

## Нерешённые вопросы и ограничения
- **Несовпадение валюты:** таблица — ₽, прежний прайс — ₸. Подтвердите валюту и поправьте заголовки.
- **Структура «Услуги»:** одна вилка цены на услугу, а в прайсе цены зависят от длины волос — прежняя детальная сетка по длинам не воспроизводится, пока ее не внесут строками.
- **В таблице нет полей** «Чему научится ученик», «Уровень подготовки» (курсы) и отзывов; эти блоки не выводятся. Блок «Отзывы» на главной остаётся заглушкой.
- **Тексты карточек (главная)** — формат «строка = карточка» мой выбор, подтвердите.
- **Тексты страниц** курсов (title) подставляются скриптом: поисковики могут видеть общий заголовок. Это особенность статического сайта без сервера.
- Адреса страниц курсов связаны с названиями в таблице через backend (`COURSE_SLUGS`); новый курс открывается на `education/course/?id=…`.
- Картинки услуг, курсов и моделей — временные иллюстрации, подбираются по ключевым словам (`js/config.js`).

## Что сделать вручную
1. Открыть `tools/check-api.html` и убедиться, что API отвечает.
2. Обновить код Apps Script из `gas-backend` (добавлен тип `other`) и выпустить **новую версию** развёртывания.
3. Заполнить таблицу и поставить статус «Готово».
4. **Один контролируемый тест заявки** (попадёт в настоящую таблицу): на странице «Контакты» → «Другой вопрос» отправьте имя «ТЕСТ не обрабатывать», телефон `+7 900 000-00-00`, затем удалите строку в таблице заявок. Либо запустите `runAllTests()` в Apps Script: он использует временные таблицы.
5. Положить настоящие фото в `images/portfolio/` или указывать ссылки в таблице.
