# CHUPROVA BEAUTY — сайт

Статический многостраничный сайт. Страницы генерирует `python3 build.py`, контент подгружается из Google Sheets (Apps Script API), заявки уходят в отдельную таблицу.

- `INTEGRATION.md` — как устроена интеграция, соответствие полей таблицы и сайта, что сделать вручную
- `js/config.js` — адреса API и настройки (картинки-заглушки, страницы курсов)
- `js/core.js` — загрузка контента (кэш, таймаут), отправка заявок, форматирование
- `js/render.js` — подстановка данных в страницы, состояния загрузки/ошибки/пусто
- `js/forms.js` — единый механизм отправки всех форм
- `script.js` — меню, галерея, вкладки; запуск загрузки контента
- `tools/check-api.html` — проверка API контента (только чтение)
- `images/portfolio/` — сюда класть настоящие фото работ, если в таблице указано имя файла

Локальный просмотр: `python3 -m http.server` в этой папке и открыть `http://localhost:8000/`.
